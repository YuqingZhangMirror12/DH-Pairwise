# 实验状态与下一步

状态快照：2026-09-21。先前登记的七路训练、42 个新分类头评估端点均已完成；本次 GitHub 上传没有新增训练。本文件不把计划写成已验证成果。

## 已完成的关键对照

- **C1/C2 等容量对照**：局部候选残差信息有收益；C1 仍保留全局分类路径，不能说完全放弃全局输入。
- **S7 M12 + fresh C8/C16 五类局部输入对照**：all_tokens、matched_tokens、matched_edges、edge_seed、edge_multi。主要有效信号是局部端点输入降低误报、改善排序；召回仍不足。对应关系／残差或多个候选没有稳定超过端点头。
- **G0/G1、Attention 深度续训与谱摘要**：未形成比局部证据选择更稳定的突破；不能说仅增大模型就能修复真实域得分。
- **Matcher M12→M16→M20 与相同预算 Scorer**：困难泛化非单调，不能据轮次更多直接选 M20。
- **采样／尺度／context 干预**：已经定位敏感路径，不等于已经训练验证最佳归一化方式。
- **dustbin 固定解码诊断**：40 个已有诊断样本，不是重新训练；简单硬拒绝损失真接缝。见 [详细结果](DUSTBIN_DIAGNOSTIC.md)。

具体固定预算数字见 [RESULTS.md](RESULTS.md)，网络与输入定义见 [HANDOFF.md](HANDOFF.md)。

## 三个不同瓶颈

在 295 个保留敦煌正例中，最多五个位移候选覆盖 250 个正确位置；原生产 Layout 正确 216 个。
使用多候选 Scorer 最高分位姿后：45 个没有正确备选、33 个有正确备选但选错、74 个选对但分类拒绝、143 个选对且接受。这个替换是诊断，未改生产 Layout。

因此必须分别改善 **提案覆盖、候选排序、Pair 接受**，不能把它们混成一个低 Recall 原因。

低支持组也有证据分布差距：训练输出中较少一侧 ≤32 个去重端点，正 pair 606 个、负 pair 11,885 个；606 个正 pair 中有 316 个选中错误 Layout。真实集端点头拒绝的 68 个正确 Layout 中，52 个属于少支持组。标签为正不代表局部候选就是真缝，不能简单重复错误候选作为正训练输入。

残差通道干预能救回一部分真缝，也会增加误报；不是可以直接删掉残差的证据。保留对应强度、dustbin 与残差应逐项训练对照，不能假设信息越多一定越好。

## 待执行，不能声称已经完成

1. 按用户方向建立新的 4 层、96D 局部 Scorer，并独立比较 4/8 heads，保留同预算控制。
2. 在 Pair 邻接标签之外，引入候选正确性／排序监督，避免正 pair 的错误候选被统一当正接缝。
3. 让仿真训练中 Matcher 的实际输出覆盖少支持、高残差但可信的真接缝，以及几何看似一致的负例。
4. 在同一候选集合上逐项比较 Q、局部 dustbin 信息和鲁棒残差表达；不把整圈未匹配比例当作短接缝否决项。
5. 评估物理采样一致性与候选稳定性；不得用真实测试集反复选超参数后宣称盲测泛化。

“局部证据应进入 Scorer”有受控实验支持；“唯一根因已找到、Recall 已解决”没有。
