## 先读这六点

1. 任务输入是两片的 **800×800 二值 Mask 与最多512个有序轮廓点**，不是RGB文字纹理。输出“能否拼接”的分数与一个二维平移 Layout；目前不估计旋转。
2. **固定16px复杂头·E32、Patch/Context轻头·E32、Q/几何轻头·E32，确实共用同一只 v14 训练并选出的 E32 Matcher，训练头时全部冻结。** E32不是随机未训练网络，也不是v17 Matcher。
3. 固定16px指同簇**所有原始局部候选二维位移的最大两两距离≤16px**。这不是距GT的半径，不是沿轮廓的间距，也不是simple版的16px半径。推理不用GT。
4. 同一簇取精确 `(i,j)` 并集，重复点对只保留一次，各自保留在线原始 `Qij`；**每个保留簇分别经过同一个Scorer，最后按Scorer最高分选Layout**。不是先选Q最强簇才只评分一次，也不把不同位姿的簇混成一个并集。
5. 已完成结果支持“轻头在敦煌的排序／布局更好”，不支持“任何简单头在所有真实集都更好”。三个同E32版本敦煌摆对数为 **189→240／236（共292正例）**；但Patch轻头的Turufan分类F1为80.08%，低于复杂头82.26%。
6. 内部审计覆盖858条模型×失败记录，849条严格复现：问题分布在**候选搜索的早期截断、复杂头显式扣分、轻头聚合后的学习读出**。新搜索对照与两个新Pooling头正在实验，尚不能把诊断收益称作已训练模型收益。

## 4. 从Matcher到候选：每步做什么

下面的“一句话例子”是解释运算，不是另造实验数据。默认谈固定16px系列；旧S7、simple及mergefix差异已单列。

| 步骤 | 网络／运算 | 一句话直观解释 |
|---|---|---|
| 输入 | Mask＋有序有效轮廓，800画布、N≤512 | 420个有效点后面的padding不应当作真对应；px均为模型画布坐标。 |
| 多尺度Patch | 每点7／16／32／64px窗口，采样到16×16 | 小窗口看缺口，大窗口看边缘整体转弯，并不是把原图RGB送进ResNet。 |
| 共享CNN | 3×3卷积＋GroupNorm＋SiLU＋MaxPool；1→24→48→64，投影96维 | 所有点、两片、四尺度共用同一把形状特征尺子。 |
| 尺度门控 | 四尺度学习加权成局部F，96维 | 该点可以更依赖小尺度；尺度权重不是Sinkhorn的Q。 |
| 本片上下文 | 坐标编码＋两块circular1D卷积残差 | 一个点先看本片相邻轮廓点，补充曲线连续性；按采样序列仍可能受密度影响。 |
| 跨片上下文 | 对侧最多32个landmark摘要，1次双向4头Attention | 每点先看对片整体摘要，但这不替代后面的所有点对精细比较；不是每16个Patch固定一组。 |
| primal／dual | Context经两套96×96角色投影 | 同一形状从两个互补角色产生匹配描述子，不是两次独立Matcher。 |
| 完整affinity | A每点与B每点的对称点积 | 在摘要上下文之后，仍然计算完整N×M局部点对相似度。 |
| partialSinkhorn | 单次调用，含100次内部数值迭代、未匹配质量 | 允许一段边找不到伙伴，输出完整Q及dustbin；Q不是“整个Layout正确概率”。 |
| 稀疏候选边 | 最低Q门槛＋每行或列Top-2 | 弱真点对可能未进这一步；后面的union不能自动把它恢复。 |
| 位移投票 | 由保留边的二维位移形成占用投票bin | “前128模式”是128个位移投票模式／bin，不是只保留128条点对。 |
| 种子 | 从模式中选最多16个分散的初始位移 | 这些是稳健局部拟合的16个起跑位置，不是16个学习token或GT候选。 |
| 局部拟合 | Q、弧长、方向性损伤／定位核 | 一组点共同拟合一个局部位移；有限退蚀与精确定位不使用同一种惩罚。 |
| T16归簇 | 原始局部位移的完整连接，两两最大距离≤16px | 位移0、12、24不能因相邻都近就链式合成一簇。 |
| 精确并集 | `U = unique {(i,j)}` | 同一条边出现3次，Q=0.6仍是0.6，不变成1.8；不同边各保留自己的Q。 |
| 联合初始Layout | 全并集稳健拟合共同平移，保留物理穿插检查 | 不直接拿“一个最好局部片段”的位移替代整簇证据。 |
| 候选预算 | 通常最多8簇，按绝对Q×观测弧长支持预选 | 8是最终候选上限，和前128模式、16种子属于不同层；不同簇仍互斥。 |

`16px一致性`、`20px训练／评价正确性标签`、`0.20–0.80分类阈值搜索`是三种不同阈值。相互一致的错对应也可能形成很强的负例簇，不能把“进簇”直接等同于“正确”。

## 5. Scorer三种架构，以及输入Q到底怎么用

### 5.1 复杂Consensus头（263,816参数）

Scorer不重新编码原Mask，读取Matcher的局部F与Context H。每簇以**两侧去重端点为token**，不是每条点对独立一个token。

| 环节 | 实现 | 一句话例子 |
|---|---|---|
| 并集回读 | 阈值版 `Wij=Qij·1[(i,j)∈U]`；mergefix／simple仍方向性加权 | Q=0.6与0.2混合对端特征为75%／25%，另保留绝对总量0.8，不丢掉强弱。 |
| 端点特征 | 本端F／H、对端加权摘要＋17项质量／残差等 | 网络同时知道“看起来像什么”“证据有多少”“在该位姿下是否一致”。 |
| token投影 | Linear401→96＋LayerNorm＋GELU | 把不同单位的特征投进共同96维空间。 |
| 两个交互块 | Self-Attention→Cross-Attention→FFN，96维、4头，含残差 | 同片分散支持先交流，再看对片对应支持；簇间不混合Attention。 |
| 局部输出 | 支持／未知／冲突三类＋定位可靠度 | 一个退蚀点可以不适合精确定位，但仍提供有限兼容证据。 |
| 共同精修 | 定位可靠度与方向残差修正平移 | 用整簇可靠点修摆放；阈值版最终位姿仍受原成员共同位姿约束。 |
| 最终位置重算 | 用新Layout重算残差，再调用同一头 | 不是旧位置打分后偷偷换新位置，也不增加第二套头参数。 |
| 证据积分 | 质量×观测弧长×支持／冲突概率 | 不把未观察到的长弧或重复采样当成额外接缝支持。 |
| 读出 | `z=b+a·log1p(E+/32)−c·log1p(E−/32)−d·overlap`，a/c/d经softplus | 支持加分，冲突和重叠显式扣分；再sigmoid得到簇分数。 |
| 赢家 | 每簇分别评分，取最大logit对应的位姿 | Q最多的簇未必胜出；没有候选则拒绝，不是神经网络“推理出0分”。 |

参数分解：输入38,784；两层交互224,448；端点输出、定位与读出584。旧S7 matched_tokens C16头178,979参数，新复杂头多84,837（47.4%）。多簇与两次前向增加计算，但共享参数，不按8簇复制8套头。

### 5.2 Patch/Context整簇轻头（34,529参数）

它已经是“输入去重点对的Patch／Context特征＋Q＋几何，直接输出整簇分数”的方案；**没有局部三分类、Attention、显式冲突／重叠扣分、神经位姿精修**。仍保留候选生成的物理阻断和作为输入的overlap等统计，不等于没有几何。

1. 每条唯一边 `(i,j)` 读取原始Q，平均／差值组合两侧F与H得到384维，再加8项Q／残差信息，共392维。
2. 点对MLP `392→64→32`，GELU：把每条边编码成32维证据特征h。
3. 定义 `w=Q×观测弧长`，计算 `mean=Σ(w·h)/Σw`；另取逐通道 `max(h)`。**max没有再次显式乘Q，但前置点对MLP已看到Q，不能称其完全不看Q。**
4. mean32＋max32＋16统计＝80维，经 `80→64→32→1` 输出簇logit／sigmoid。
5. 16统计另保留点数、ΣQ、ΣQ×弧长、mean/maxQ、有效点数、双侧覆盖、残差、dustbin、簇外Q、overlap、成员位移直径与成员数。因此条件均值归一化不等于丢掉绝对证据量。

例：53条边的总Q比27条边更大，但错误簇在某些学习特征通道的max更突出，下游权重仍可给它更高分——main/85就是已实际发现的情况。

### 5.3 Q／几何统计轻头（3,201参数）

同一去重union与共同Layout，只取相同16统计，经 `16→64→32→1`；没有Patch/Context直读、点对MLP或mean/max特征池化。例：它可以学到“高覆盖、低残差、足够总Q”更可信，但不能直接检查两个Patch的形状特征是否相容。Q本身仍来自同一Matcher，不是完全去掉神经匹配。

### 5.4 新Pooling对照（各32,481参数，尚无最终成绩）

| 版本 | 聚合方式 | 明确保持／边界 |
|---|---|---|
| mean-only | `Σ(w·h)/Σw`，去掉max | 同392→64→32边MLP与16统计，48→64→32→1整簇头 |
| bounded-sum | `log1p(Σ(w·sigmoid(h)))` | 不除以总质量，不取最大；各边贡献可追溯 |

两新头都保留overlap输入、原搜索和T16，避免同时改多个因素。相对原mean+max头少2,048参数，**不是等参数容量实验**。sum聚合各贡献非负，但最终MLP不受单调约束，仍可能降分；不能未经结果就承诺“点多必然更可靠”。

### 5.5 损失与训练

复杂头包括候选BCE、簇间排序、局部状态、定位与扩展一致性，系数1／0.2／0.1／0.1／0.1。轻头只保留候选BCE＋0.2×簇内正确／错误排序softplus，margin1。**已经有ranking loss，不是“补一个排序损失”就算发现根因。** 正Pair中的错误位姿是负候选，不能因Pair为正就全标正。

原头通常min16／max48轮，每2轮CAL／SELECT；连续3次没有≥0.001改善则LR×0.5，最多两次且有后续观察。FP32、有效batch32、头初始LR1e-4、weight decay1e-4、梯度裁剪5。后续单卡micro32是保持优化batch32的执行调整，不是把batch或LR任意放大。课程实验用其单独锁定的24K更新合同，不套旧平台轮次规则。

## 10. 下一步应该如何改进，而不是继续猜原因

1. **优先接收完整搜索对照。** 先确认Top3、模式范围、种子覆盖分别救回多少正确候选，同时破坏多少原成功／增加多少FP。不要把oracle GT种子恢复率当作可部署搜索收益。
2. **用重新训练的Pooling结果验证读出假设。** mean-only与sum分别和同E32基线比，报告全量与来源保留TEST、SIM／REAL选模、参数差异、排序和拒绝的分解。未重训的旧输入置零不能替代这一结论。
3. **只组合独立有净收益的因素。** 搜索、评分overlap和Pooling不要一起无记录修改；保留单因素结果、配对退步和误报代价。更多候选会竞争final8，召回不必单调提升。
4. **检验学习信号而不是只说“某层坏了”。** 现有ranking loss的正确／错误候选覆盖、梯度规模、max通道由哪些边主导、在真实低Q少点区间的读出斜率，都应保留实际激活／权重与图像证据。数据量和Q相近仍低分的案例与真正缺证据的案例分开。
5. **公平扩展到v17／课程。** 若要判断v17上哪个头最好，固定同一只已训练v17 Matcher，再分别训三种新头；不要重训三只不同Matcher制造混杂。课程与混合保持相同曝光和预算，才能区分顺序效应与更多数据／计算。
6. **不要把降阈值当作所有问题的补丁。** 在REAL-CAL标定后报告召回—误报代价；对候选缺失、错排必须分别修复。真实TEST不选阈值、几何或新机制。

目前没有证据宣布16px是所有真实样本的全局最优，也没有证据说所有失败都来自max／mean。已有证据足以安排上述受控实验，不足以热改运行中的源或删除物理约束。
