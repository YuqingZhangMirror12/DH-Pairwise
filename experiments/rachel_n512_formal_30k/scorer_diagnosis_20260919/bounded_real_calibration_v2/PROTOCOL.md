# 受限真实域阈值复算

用户要求排除0.01、0.1这类阈值，并复算前一日实验。执行前采用以下约束：

- 允许阈值为0.20至0.80，步长0.01；以校准折最大F1为主策略。
- F1并列时，依次选最接近0.30、Precision较高、阈值较高的操作点。
- 另外报告统一固定0.30和“允许范围内召回至少95%”两种策略。
  后者不可达时使用0.20并标记未达到目标，不能越界降低阈值。
- 不训练模型，不校准logit，不重新缩放score，不重排Layout候选。
- 18组历史固定C16端点及本轮8组端点全部保留，不从真实集选择epoch。
  18组历史端点包含C0/C1/C2、S7原头续训、5种新头输入、G0/G1、
  1/4层Attention续训、3组谱摘要、M16/M20各自等预算新Scorer。
- 完整复用上一轮的5折、来源分组和负例清单；不根据分数重新挑负例。
  Dunhuang为295个保留正例、39个原有同来源负例、469个跨来源负例；
  Turufan为301正、301跨来源负。该标注基于来源假设，不是逐对人工核验。
- 同一已知来源、同一写本正反面、同一已知重复碎片不跨当次校准／测试。
  每次4折校准、1折测试，完整轮换一次；未做多随机种子重复。
- 原正例／同来源负例分数复用。历史模型只补推新跨来源负例，使用原
  冻结源码与batch1推理；这不是更改训练batch。本轮8组全量复用上轮预测。
- 谱特征仍使用原CPU batch1 Matcher输出和float64 SVD摘要；新负例摘要
  单独计算并按输入绑定。原训练集归一化统计不变。
- 旧SIM阈值也在同一新负例清单上复算，保证变化不来自更换负例集合。
- 原始Layout成功仍为有效位移且误差≤20px；Turufan仍没有Layout GT。

本轮是用户在看过上一轮CV后追加的操作约束敏感性分析。逐折阈值没有
使用本折测试标签，但不能因此消除此前人工筛选、架构探索和反复分析
带来的研究层面选择偏差。不要将26组最高分当成新的无偏盲测冠军。

结果目录与旧实验分开，不覆盖任何已有checkpoint或SIMVAL freeze。
所有任务是有限推理队列，不会持续占用GPU或自动追加训练。
