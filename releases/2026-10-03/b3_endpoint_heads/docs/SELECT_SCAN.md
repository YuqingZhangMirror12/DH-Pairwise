## 2. 冻结选模规则与指标含义

规则 `stratified_native_layout_band_loss/2` 在扫描前冻结：

1. v17_filtered、v17.5、v18、严格直缝的权重为 **0.3 / 0.3 / 0.3 / 0.1**。前三个阶段内部 Gen2/3/4/5 等权；严格直缝为独立 stratum，不冒充某个 Gen。

3. 进入最高宏平均 Layout 的 **0.005（0.5 个百分点）**容差带后，依次按最低宏平均完整 Matcher loss、较高 Layout、较早 update 决胜。候选覆盖率仅诊断，不参与选模。
4. loss 按每一对完整原生 Matcher 损失计算，包含正负例；物理 microbatch=1。不能拿它替代后续新 Scorer 的效果。

最高宏平均 Layout = **99.1053%**；准入下限 = **98.6053%**；容差带内更新：5667, 7667, 9667, 13667, 29667, 31667。
